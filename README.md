### Implementing Random Forest Regression for Thermal Comfort prediction based on ASHRAE Global Thermal Comfort Database II
The code includes:
Data cleaning, data imputation (MICE), testing of skewness and outliers of the variables with the use of a custom function (syntax included in the file), transformation of variables for handling skewness and lots of trial and error regarding picking the appropriate variables for a succesful prediction and implementing an appropriate model.
Comments and explanations of my thought process are also included, mainly in Greek.
